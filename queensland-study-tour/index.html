01 / THE IDEA · 概念

What is music visualisation?什么是音乐可视化？

Music visualisation translates changing musical features and performance gestures into moving images. It can reveal waveforms, spectra and rhythmic patterns, or become an interactive artwork shared with an audience. The musician still decides which sonic events matter and how they should look.

音乐可视化把随时间变化的声音特征与表演动作转译为动态图像。它既能帮助我们观察波形、频谱和节奏，也能成为与听众共同参与的视觉作品。音乐人仍然决定哪些声音事件重要，以及它们应该如何呈现。

WHY MUSIC STUDENTS · 为何面向音乐学生

Why teach this to musicians?为什么要教音乐专业学生？

A

Listen with another sense换一种感官去听

Compare timbre, dynamics and form through visible evidence. The image can start a musical question; it is not a substitute for listening.

借助可见的线索比较音色、力度和曲式，让图像成为提出音乐问题的起点，并保留聆听本身的判断。

B

Author the mapping由音乐人定义映射

A crescendo need not simply make everything bigger. You can choose to show tension through density, distance, colour, or stillness.

渐强不一定只是“所有东西变大”。你可以用密度、距离、色彩，甚至静止来表达张力。

C

Make a working prototype做出可运行原型

AI Studio lowers the barrier to a browser prototype, so a performer or composer can test an idea and discuss it with a visual collaborator.

AI Studio 降低浏览器原型的制作门槛，让演奏者或作曲者先验证想法，再与视觉合作者讨论和完善。

02 / LINEAGE · 历程

From painted frames to live systems从逐帧绘制到实时响应

1920s–40s

Visual music by hand 手工视觉音乐

Walter Ruttmann's Lichtspiel: Opus I (1921) set abstract forms in motion. Oskar Fischinger later painted Motion Painting No. 1 (1947) frame by frame to Bach.

瓦尔特·鲁特曼的《光影：作品一号》（1921）让抽象形态动了起来；奥斯卡·费钦格后来逐帧绘制《动态绘画一号》（1947），配以巴赫的音乐。

Opus I ↗ MoMA ↗
Video era

Audio drives animation 音频驱动动画

In pre-rendered video, motion designers turned audio into amplitude keyframes or spectrum graphics, then polished each shot before export. The pictured After Effects template is one example.

在预先渲染的视频流程中，动态图形设计师可把音频转换成音量关键帧或频谱图形，再逐镜头修整和导出。右图是 After Effects 模板案例。

04 / FOR MUSICIANS · 音乐人的应用

Where could you use it?音乐专业学生能用在哪里？

These are project directions for School of Music students, not claims about existing UQ productions.

以下是面向音乐学院学生的创作方向，并非昆士兰大学已有项目的陈述。

PERFORMANCE / 演出

A visual partner on stage舞台上的视觉合奏者

Map a live solo, ensemble, or electronic set to projected movement that follows the performance rather than a fixed video.

把独奏、重奏或电子音乐现场映射成随演出变化的投影，而不是播放固定视频。

COMPOSITION / 创作

Show the structure of a piece呈现作品结构

Prototype how motifs, texture and dynamics unfold, then include the visual piece in a portfolio or installation.

把动机、织体、力度的展开做成原型，用于作品集或装置作品。

EDUCATION / 教学

Make listening discussable让聆听更可讨论

Let students compare rhythmic accents, phrase shapes or spectra while they listen, perform and question what the display omits.

让学生边听、边演奏、边比较节奏重音、乐句轮廓和频谱，并讨论图像未呈现的部分。

RESEARCH / 研究

Build a testable interface制作可测试界面

Explore audience response, multimodal interpretation or performance interaction through a small prototype before a larger study.

用小型原型探索观众反应、多模态理解或演出交互，为后续研究提供可测试界面。

01CANVAS

Start with a visible scene先做出可见画面

Ask for one responsive page and one animated canvas. Check that it fills the available space before adding sound.

先要求一个响应式页面和一张会动的 Canvas；确认布局正常，再接入音乐。

PASTE INTO BUILD / 复制到 BUILD
Create a responsive single-page web app for an interactive music visualiser. Use HTML Canvas for the main artwork. Begin with a calm animated scene and a clear title, Play button, and mode selector. Use no external API or paid service. Keep the code readable and add an accessible label for the canvas. Do not add audio yet.

Check / 检查 Resizing keeps the scene visible; no errors appear. / 缩放窗口后画面仍完整，且没有报错。

02AUDIO

Let a local recording drive it让本地音乐驱动画面

Load the music you just made with AI, or another recording you may use. Add playback and an AnalyserNode; audio stays in the student's browser.

载入刚用 AI 生成的音乐，或其他有使用权的录音；加入播放控制和 AnalyserNode，音频在学生浏览器内处理。

PASTE INTO BUILD / 复制到 BUILD
Add a local audio-file picker and Play/Pause control. Use the Web Audio API: connect the selected audio element to an AnalyserNode, read frequency and waveform data every animation frame, and animate the canvas from real audio data. Keep the file local in the browser. Show a helpful empty state before a file is chosen. Preserve the current layout.

Check / 检查 Silence and music look different; pause freezes the response. / 静音与音乐的画面不同，暂停后响应停止。

03MAPPING

Make musical choices explicit明确声音如何变成图像

Separate low, middle and high frequency energy. Ask for each band to control a different visual property, then judge the result by ear.

把低、中、高频能量分开，为每段设计不同的视觉属性，再用耳朵判断映射是否合理。

PASTE INTO BUILD / 复制到 BUILD
Keep the working audio upload. Split the analyser's frequency data into low, mid and high bands. Map low energy to the main shape's size, mid energy to its movement, and high energy to fine details. Smooth the values so the visuals do not flicker. Put three small labelled meters on screen so I can verify the mapping. Change only the visual mapping and meters.

Check / 检查 Try contrasting tracks or clap and hum; can you predict which element changes? / 换不同音乐、拍手或哼唱，能否预测哪一部分会变化？

04CONTROL

Give the audience agency让观众参与

Add one interaction first: pointer movement, drag-to-paint, a mode switch or a sensitivity slider.

先增加一种交互：指针移动、拖动画墨、模式切换或灵敏度滑块。

PASTE INTO BUILD / 复制到 BUILD
Add a mode selector with three views: waveform, frequency spectrum and expressive ink. Add a sensitivity slider that changes how strongly the artwork reacts, and support mouse dragging to leave a short visual trace. Keep all existing audio controls working. Give each control a visible label and keyboard access.

Check / 检查 All three views respond to the same file; mouse and keyboard controls work. / 三种视图都能响应同一段音频，鼠标和键盘可以操作。

05POLISH

Make it safe to perform让作品适合现场使用

Add microphone as an opt-in input, then test permission denial and reduced motion. Keep a mute control and a clear stop state.

把麦克风作为主动选择的输入方式，测试拒绝授权和减少动态效果；保留静音与停止控制。

PASTE INTO BUILD / 复制到 BUILD
Add an optional microphone input that starts only after I press a clearly labelled button. In Google AI Studio Build, add "microphone" to requestFramePermissions in metadata.json so the preview can ask for permission. If permission is denied, explain how to use local audio instead. Add Mute, Stop and Reduced motion controls. Respect prefers-reduced-motion. Do not use the camera or upload recordings. Keep the existing file mode and visual modes intact.

Check / 检查 Approve the AI Studio preview acknowledgement, then deny browser microphone permission and try a local file; the app still works. / 先确认 AI Studio 预览中的权限提示，再拒绝浏览器麦克风授权并改用本地文件，软件仍可运行。

06SHIP

Test, revise, download测试、修改、导出

Use the preview and Code tab to resolve one error at a time. Keep the last working version. Download the project ZIP; a multi-file app needs its project run commands and a localhost development server for final device tests.

通过预览和 Code 页面逐个修复错误，保留上一个可运行版本。下载项目 ZIP；若生成多文件应用，请按项目的运行命令启动 localhost 开发服务器，再做设备权限测试。

PASTE INTO BUILD / 复制到 BUILD
Audit this music visualiser without redesigning it. Fix console errors, check that file audio, microphone permission denial, three visual modes, keyboard controls, Mute and Reduced motion all work. Explain each changed file briefly. Preserve the last working behavior and make only targeted fixes.

Deliver / 交付 A working link or ZIP, one audio example, a 30-second screen recording, and a short mapping explanation. / 可运行链接或 ZIP、一段示例音频、30 秒录屏与简短映射说明。
