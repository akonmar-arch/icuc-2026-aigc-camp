用 Gemini 做音乐可视化Interactive Music Visualizer with Gemini — generative UI

The radical idea: students never write code. They describe what they want in natural language and Gemini generates runnable HTML/JS; the student only iterates the prompt and the aesthetics. They load a music track they created or may use, make the visuals genuinely REACT to the sound (bass / mid / treble + beats), restyle the result as expressive Chinese ink-wash, and share a working URL.
核心思路：学员不写代码——用自然语言对 Gemini 描述，让它生成可运行 HTML， 自己负责迭代提示词与审美。载入自创或获授权的音乐，让画面真正随声音反应 （低/中/高频 + 节拍），再打磨为有笔触和留白的水墨，最后分享可运行链接。

当天产出 / Deliverable — 可在浏览器打开的交互作品 + 课堂同学可访问的链接 + 30s 演示视频 + Prompt 日志（≥5 轮迭代）

无障碍与安全 · Accessibility & Safety（先读 · read first）

本课默认有闪光、抖动、强对比脉冲——对光敏性癫痫是真实风险。下列约束全程适用并计入评分，括号内英文句可直接粘进 prompt。Flashing/shake/high-contrast pulses are a real photosensitivity risk; these apply all day, are graded, and the English lines paste straight into prompts.

防闪光 Anti-flashCap any flash to under 3 per second, never a full-screen pure-white strobe; keep flashes local and brief.
减弱动效 Reduced motionRespect @media (prefers-reduced-motion: reduce): disable screen-shake and heavy bloom, soften pulses to opacity fades.
可暂停/静音 Pause & muteAlways keep a visible Pause and Mute control; nothing auto-plays loud.
对比度 ContrastEnsure text and the red seal meet WCAG AA contrast on the #FAF6F0 paper.
字幕 / 声明 Caption & notedemo 视频加一行字幕；投屏前口头提示「含闪光与运动」。 One caption line on the clip; say "contains flashing & motion" before the showcase.

拆解法 · 一步一步来 · Decompose, one step at a time

不要一次让 AI 把整个页面做出来。把大目标拆成一串「单一目的」的小步骤——一次只加一件事，加完就验证，能跑再加下一步。下面这把「拆解阶梯」就是今天五个练习的主线，照着走，不会乱。Never ask the AI for the whole page at once. Break the goal into a ladder of single-purpose steps — add one thing, verify it runs, then the next. This ladder is the spine of today's five exercises; follow it and you won't get lost.

拆解阶梯The decomposition ladder
骨架 → 反应 → 风格：先让它动，再让它「听」，最后才让它「美」。 Skeleton → reactions → style: make it move, then make it listen, and only then make it beautiful.
  1. 搭骨架 Skeleton — 一个 HTML 文件：全屏 canvas + 渲染循环 + 暂停/静音按钮。验证 check: 空白画布在持续刷新。 → Ex.1One HTML file: a full-screen canvas, a render loop, and Pause/Mute. Check: the blank canvas keeps repainting.
  2. 进声音 Load the audio — 载入并能播放/暂停一段本地 .mp3。验证: 能播、能停。 → Ex.2Load a local .mp3 with play / pause. Check: it plays and pauses.
  3. 取一个数 One signal — 接 FFT，先只把低频一个数字打在屏幕上。验证: 出声时数字在跳。 → Ex.2Wire up the FFT and print just the BASS number on screen. Check: it jumps with sound.
  4. 一个映射 One mapping — 让那一个数字驱动一个视觉（一个圆随低音缩放）。验证: 鼓点一来圆就涨。 → Ex.2Let that one number drive ONE visual (a circle scales with the bass). Check: it pulses on every kick.
  5. 逐段添加 Add bands — one at a time — 中频→涟漪，高频→粒子；一次只加一段，加完再加下一段。验证: 每段单独确认对了再继续。 → Ex.2Mids → ripples, treble → particles — add ONE band at a time, confirming each before the next.
  6. 加节拍 Beats — 检测重拍 → 闪一下 / 冲击波。验证: 重拍时画面闪一下。 → Ex.2Detect strong onsets → one flash / shockwave. Check: it flashes on a strong beat.
  7. 抹平 Smooth — 所有数值做 lerp 平滑。验证: 不再抖，像呼吸。 → Ex.2Smooth every value with lerp. Check: no jitter — it breathes.
  8. 一种交互 One interaction — 只选一个「招牌动作」做到爽。验证: 你会想再玩一次。 → Ex.3Pick exactly ONE signature interaction and make it satisfying. Check: you want to do it again.
  9. 上风格 Style — last — 最后才做水墨：渗墨·飞白·留白·印章，让音乐变化真正改变笔触。验证: 像真水墨，不是灰色几何。 → Ex.4Only now the ink-wash pass — bleed, flying-white, negative space, a red seal; let musical changes shape the strokes. Check: real ink-wash, not grey shapes.
  10. 发布 Ship — 导出 → 分享 → 课堂可访问的链接 + demo + prompt-log。验证: 在另一台桌面电脑打开能跑。 → Ex.5Export → share → a class-accessible link + demo + prompt-log. Check: it runs in another desktop browser.
四条铁律 · Four golden rules — ① 先骨架，再血肉，最后皮肤（结构 → 反应 → 风格）。② 一次只改一个变量。③ 加完就验证，能跑再继续。④ 永远留一份「上一版能跑的」项目。
① Skeleton → flesh → skin (structure → reactions → style). ② Change one variable at a time. ③ Verify after every step; only continue when it runs. ④ Always keep a last-known-good file — rolling back and re-describing IS the skill.

效果配方 + 样例 · Effect recipes & samples

辉光 / 泛光 · Bloom
Add an additive bloom/glow pass so bright parts halo and bleed light into the paper.
节拍粒子 · Beat particles
On each detected beat, emit ~30 glowing ink droplets that fly outward and fade.
拖尾 · Trails
Don't fully clear the canvas each frame — fade it ~8% so motion leaves silky ink trails.
冲击波 · Shockwave
On click or a strong onset, send an expanding ring that warps everything it passes.
景深 / 视差 · Parallax
Layer 3 depths of strokes; move them at different speeds with the mouse for depth.

Gemini Visualizer Workshop · 5 道循序练习 · five sequential exercises
Exercise 1

Hello Canvas第一段不写代码的代码

15 min

目标 — 感受自然语言 → 可运行 HTML 的瞬间，建立信心。Goal — Feel the moment natural language becomes runnable HTML, and build confidence.

Google AI Studio Build — first prompt
Build a single-file HTML page with one centered black circle on a
white background. When I click anywhere, the circle should bounce
once (scale up to 1.5x and back). Use vanilla JS, no libraries.
Make it elegant and minimal.
步骤 · Steps
  1. 打开 Google AI Studio 的 Build 模式，选择网页应用，贴第一个 prompt。Open Google AI Studio Build, choose a web app and paste the first prompt.
  2. 预览运行，点几下看交互。Run the preview; click around to see the interaction.
  3. 截图 + 存下这一版 HTML。Screenshot it and save this version of the HTML.
  4. 自问：你能用一句话描述它在做什么吗？Ask yourself: can you describe what it does in one sentence?
产出 / Deliverable
1 个能跑的 HTML 页面 + 截图。One working HTML page + a screenshot.
讨论 / Discussion
  1. 第一次「看到代码运行」是什么感觉？How did it feel to "see code run" for the first time?
  2. Gemini 多给了 / 少给了什么？What did Gemini add / leave out?
  3. 这段代码你看得懂吗？需要看得懂吗？Can you read this code? Do you need to?
✦
教学点 — vibe coding 范式下「看不懂代码」不是失败——能描述、能验证才是新技能。Teaching point — In the vibe-coding paradigm, "not reading the code" isn't failure — describing and verifying is the new skill.
Exercise 2

Audio Lives in the Page让声音住进页面

25 min

目标 — 让画面真正「听见」音乐：不是一个圆变大，而是低/中/高三频段 + 节拍各自驱动不同效果。在 Ex.1 基础上同一对话迭代；报错就粘回 Gemini。Goal — Make the visuals truly "hear" the music: not one circle scaling, but bass / mid / treble + beats each driving a different effect. Iterate in the same chat from Ex.1; paste errors back to Gemini.

Iterate in the same chat
Now load a local .mp3 (small play/pause button) and drive everything with
the Web Audio API in real time. Split the FFT into 3 bands and make AT
LEAST 3 things react:
  - BASS (low)    -> the core pulses / scales on every kick
  - MIDS          -> concentric rings ripple outward
  - TREBLE (high) -> a spray of small bright particles
Add simple BEAT DETECTION: on a strong onset, fire a quick flash / shockwave.
Add a soft additive GLOW (bloom) and short motion TRAILS so it feels alive,
not jittery; smooth every value (lerp) so it breathes.
Single HTML file, vanilla JS + canvas.
步骤 · Steps
  1. 同一对话继续迭代，贴入多频段 prompt，加载自己创作或获授权的音频。Keep iterating in the same chat; paste the multi-band prompt; load your own rights-cleared audio.
  2. 先跑通基础 FFT，再逐条加：低频脉冲 → 中频涟漪 → 高频粒子。Get a basic FFT working, then add one by one: bass pulse → mid ripple → treble particles.
  3. 再加节拍闪光 + 辉光(bloom) + 拖尾；所有数值做平滑(lerp)防抖。Then add beat flashes + bloom + trails; smooth every value (lerp) to stop jitter.
  4. 录 30s，确认「安静段安静、高潮段炸」；报错粘回 Gemini。Record 30s; confirm "quiet stays quiet, the climax explodes"; paste errors back to Gemini.
产出 / Deliverable
三频段 + 节拍反应、带辉光/拖尾的页面 + 30s 录屏（要含一段「安静 → 高潮」对比）。A page reacting across 3 bands + beats with bloom/trails + a 30s screen-recording (include a "quiet → climax" contrast).
讨论 / Discussion
  1. 安静段与高潮段的差别够大吗？Is the quiet-vs-climax difference big enough?
  2. 哪个频段最难「听对」？延迟 / 过激 / 麻木怎么调？Which band was hardest to get right — laggy / too jumpy / numb?
  3. Gemini 哪一次给的代码错了？错在哪？Which Gemini output was buggy? Where?
✦
教学点 — 别让一个圆代表整首歌——拆成低/中/高 + 节拍，画面才像在「听」。bug = 沟通失败，粘报错最高效。Teaching point — Don't let one circle stand for the whole song — split into bass/mid/treble + beats so the visuals seem to "listen." A bug = a comms failure; pasting the error is the fastest fix.
Exercise 3

Add One Interaction加一个交互

35 min

目标 — 从「被动反应」变「主动可玩」。每人选 1 种作为你的「招牌动作」（宁精勿多），做得够爽。Goal — Move from "passive reaction" to "actively playable." Each person picks one as your signature move (quality over quantity) and makes it satisfying.

鼠标"When I move the mouse, the circle follows my cursor with a 0.3s lag."
键盘"When I press SPACE, trigger a brief ink-ripple accent."
麦克风"When I make a sound into the mic, a smaller circle appears and pulses with my voice."
滚轮"Mouse-wheel up = warmer color tone; down = cooler tone."
摄像头"When my face moves left/right (webcam), the visuals shift left/right."
拖动画笔"Click-drag leaves a trailing ink brush-stroke that slowly fades."
点击冲击波"On click, emit a shockwave ring that warps everything it passes through."
拍手"On a loud clap, trigger an ink-splash explosion."
步骤 · Steps
  1. 从上表选 1 种交互（鼠标 / 键盘 / 麦克风 / 滚轮 / 摄像头）。Pick one interaction from the table (mouse / keyboard / mic / wheel / webcam).
  2. 用一句自然语言把它描述给 Gemini。Describe it to Gemini in one natural sentence.
  3. 跑通后自测：你会想「再用一次」吗？Once it works, self-test: do you want to do it again?
  4. 录一段带交互的 30s 演示。Record a 30s demo showing the interaction.
产出 / Deliverable
含一种交互的页面 + 30s 带交互演示视频。A page with one interaction + a 30s demo video of it.
讨论 / Discussion
  1. 你的交互「用一次就够」还是「想再用一次」？Is your interaction "once is enough" or "want to do it again"?
  2. 交互改变了观众听音乐的方式吗？Did it change how the audience listens?
  3. 给产品经理看，他会怎么改？Shown to a PM, how would they change it?
✦
教学点 — 好的交互让人想再做一次。没有这个的交互只是装饰。Teaching point — A good interaction makes you want to do it again. Without that, it's just decoration.
Exercise 4

Style as Culture风格即文化

35 min

目标 — 把视觉做成真水墨——渗墨、飞白、留白、泼墨，而不是「灰色几何形」。继续迭代，加入下面至少 3 项。Goal — Make the visuals real ink-wash — bleed, flying-white, negative space, splashed ink — not "grey shapes." Keep iterating; add at least 3 of the items below.

Apply at least 3 of these
Restyle it as REAL Chinese ink-wash (水墨 / sumi-e), not "grey shapes":
1. Canvas = warm rice-paper cream (#FAF6F0) with a faint fibrous grain
   and lots of empty space (留白 negative space).
2. Brush strokes, NOT geometric shapes: tapered ends, varied width, wet
   edges that BLEED softly into the paper (feathered alpha).
3. Ink in tonal washes (dark -> pale, 墨分五色) + dry-brush "flying-white"
   streaks (飞白) on fast strokes; ONE restrained accent only — a
   cinnabar-red seal 印章 OR jade #5B8C7E.
4. On a strong BEAT, throw a splashed-ink burst (泼墨): droplets scatter,
   then DIFFUSE and dry into the paper over ~1s.
5. The bass pulse should look like fresh ink BLOOMING on wet paper —
   not a circle scaling.
6. A single faint vertical centre line (Beijing Central Axis), a Chinese
   serif (Noto Serif SC), and a small red seal in one corner.
Reference look: Sesshu's "splashed-ink" (haboku) landscape.
步骤 · Steps
  1. 继续迭代，套用上方 ≥3 项水墨 / 中国风处理。Keep iterating; apply ≥3 of the ink-wash / Chinese-style treatments above.
  2. 删掉一个 AI 多给、不搭的元素。Delete one element the AI over-added that doesn't fit.
  3. 保留完整 Prompt Log（所有迭代）。Keep the full Prompt Log (every iteration).
产出 / Deliverable
视觉升级后的页面 + Prompt Log（保留所有迭代历史）。The restyled page + a Prompt Log (full iteration history).
讨论 / Discussion
  1. 这些视觉元素真的「中国」吗？还是只是符号？Are these visuals truly "Chinese," or just symbols?
  2. 你删掉了哪个 AI 给的元素？为什么？Which AI-added element did you cut? Why?
  3. 不懂中国文化的观众能感觉到「水墨」吗？Would a viewer new to Chinese culture feel the "ink-wash"?
✦
教学点 — 水墨的关键不是「黑白」，而是墨分五色 + 留白 + 笔触动态；印章 / 中轴是点睛，不是堆砌。Teaching point — Ink-wash isn't about "black & white" but tonal range + negative space + brush dynamics; the seal / central axis are finishing touches, not clutter.
